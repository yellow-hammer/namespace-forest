# Namespace Forest

XSD платформы **1С:Предприятие 8** (выгрузка/загрузка конфигурации в XML).

Структура (на выбор): **`schema/<версия_платформы>/`** — например `schema/8.3.27/`, `schema/8.5.1/`; или **`8.3/<версия>/`**, **`8.5/<версия>/`** — линия платформы сверху, внутри — конкретная сборка. Цифры **8.1 / 8.2 / 8.3** в именах XSD — это namespace внутри одной линии, не обязательно отдельные папки.
